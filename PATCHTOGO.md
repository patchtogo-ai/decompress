# About @patchtogo.ai/decompress

`@patchtogo.ai/decompress` is an unofficial fork of the npm package `decompress`, version 4.2.1, republished by [patchtogo](https://patchtogo.ai) with security fixes. patchtogo is not affiliated with the upstream authors, and all credit for the original code goes to them.

- Upstream package: https://www.npmjs.com/package/decompress
- Upstream source: https://github.com/kevva/decompress at `84a8c1046946add1a6ae01c54dbebf312e4ffc85`
- This fork: https://github.com/patchtogo-ai/decompress
